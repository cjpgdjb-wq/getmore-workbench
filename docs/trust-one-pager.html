可信投放控制台：不是“更聪明的 AI 投手”，而是一套让商家敢授权、敢扩权、也敢退出的机制。四份合同，一个信任阶梯。

商家 / 投手 / 服务商 千川 · 乘方 分析 → 建议 → 执行 → 对账 信任 = 能力 × 善意 × 一致性 × 可预测性
商家不是不接受自动化，
而是不接受不可逆的自动化。
公开信息里，投手说“全域推广就是个黑盒，我根本不知道能控制什么”；广告主说“不会把程序化投放交给 LLM Agent”，因为一个小数点错误就可能是财务灾难。问题不在模型聪不聪明，而在决策不可逆、过程不可见、责任不可追。
结果不可预期它会不会拿我的钱做实验？
过程不可见它为什么这么干？
权限不可控我能叫停、能限制吗？
责任不可追出了事谁负责？
能力不可评它凭什么让我信？
关系不可逆我能不能走？
“

信任不是“相信模型更聪明”，而是“相信一套可授权、可预演、可熔断、可对账、可退出的机制”。

所以产品不叫 AI 投手，叫可信投放控制台：Agent 负责分析和提案，商家负责定边界；每一笔钱都在授权内，每一个判断都有证据，每一次执行都可回滚。

四份合同：把信任变成可验证的承诺

确认弹窗只解决“执行前看一眼”；真正决定商家敢不敢用的，是授权、证据、对账、退出四件事。

钱与权限
01

授权合同

Mandate

商家给的不是一个“开关”，而是一张有额度、有范围、有期限、可撤销的授权书。

  • 总预算 / 单日上限 / 单次动作上限 / 最大损失上限
  • 允许动作、排除场景（品牌、大促、跨账户）
  • 审批矩阵：低风险自动、中风险确认、高风险核对
  • 按账户/商品拆额度，到期自动失效
为什么
02

证据合同

Evidence

每个结论和动作，都能被商家质疑、下钻、复现；不知道就说不知道。

  • 数据层：来源、口径、时间、样本、缺失
  • 逻辑层：依据、反事实、替代方案、置信区间
  • 责任层：谁批准、错了怎么办、怎么回滚
  • 给区间，不给假精确；给“不行动”选项
有没有用
03

对账合同

Ledger

每个预测都登记，T+1/T+3/T+7 对实际；准确率公开，错误主动复盘。

  • 预测值 + 区间 + 置信度 + 方法 + 数据缺口
  • 校准曲线；分场景 / 分行业看准确率
  • 事故分级、披露时限、补偿规则、修复五步
  • 战绩可导出，不靠平台自说自话
能不能走
04

退出合同

Exit

退出权是信任的前提，不是信任的例外。

  • 一键暂停自动执行，保留只读分析
  • 一键撤销授权，待确认提案作废
  • 按时间窗 / 账户 / 动作批量回滚
  • 授权书、决策、对账、事故报告可导出

一个信任阶梯：按额度给，不按功能给

升级要慢、降级要快；降级不是惩罚，是保护。商家看到的是“再 2 周无事故可升 L3”，不是“开通自动投放”。

L0
观察只读分析、回答、复盘；不花钱。
L1
建议给建议和证据，商家自己执行。
L2
提案审批Agent 提案，人确认后执行；大多数商家的起点。
L3
额度内自动授权内自动执行，异常才找人。
L4
托管更大额度内自动，周度复盘。
升 L3：20+ 审批动作、预测误差 ≤15%、0 P0/P1 事故、商家主动开启
降 L2：单次损失 > 上限 50%、误停 ≥2 次、预测误差 >25% 连续 2 周

四个关键机制：让机制跑起来

影子模式先证明，探索保护防“人手痒”，熔断把最大损失写进产品，激励对齐解决平台 Agent 的原罪。

◐
影子模式

2–4 周只提案不执行，和人工决策对比；用“如果当时听它的”证明能力，再谈授权。

⏸
探索保护

学习期/爆发前标记“探索窗口”；“建议不动”是一等公民；人工干预先预演影响。

⚡
熔断止损

ROI 连续低于底线、损失达上限 80%、动作失败率过高时，停止自动、保留人工、先止损再解释。

⚖
激励对齐

目标由商家定义；“不投放”是合法建议；账本可导出/第三方审计；收费透明。

北极星：可信自动化消耗占比

授权内自动执行消耗 / 总消耗必须同时看预测校准（MAPE）与事故损失率，否则可以通过“什么都自动”刷高
试用分析→影子模式→首次授权→首次自动→30 天留存→扩权→推荐

护栏：别把“信任”做成“盲信”

橡皮图章率审批 <3 秒且未看证据
预测校准MAPE / 90% 区间覆盖
误停率被暂停但本可恢复
事故损失率P0/P1 损失 / 消耗
信任不是 UI，是制度；不是一次确认，是一套可验证的承诺。先让商家敢看，再让他敢信，最后才让他敢交。
