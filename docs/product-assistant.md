# 商品智能助手 · 工作区

## 1. 设计目标

一个商品对应一个**逻辑工作区**；工作区内可以有多次对话。

```text
共享工具池 / 技能池
        ↓ 绑定 + 权限
商品工作区（ProductWorkspace）
        ├ 对话 1
        ├ 对话 2
        └ 对话 N
```

工作区不是新的模型实例，也不是新浏览器页面。它是：

- 固定商品范围
- 工具 / 技能绑定
- 权限
- 商品记忆
- 多会话管理

## 2. 组织模型

A 公司是服务商，三个事业群平级、独立：

```text
A 公司（服务商）
├ 华东事业群
│  ├ 服饰生活组
│  ├ 美妆个护组
│  └ 食品饮料组
├ 华南事业群
│  ├ 数码家电组
│  └ 本地生活组
└ 品牌营销中心
   ├ 品牌投放一部
   └ 品牌投放二部
```

再往下：

```text
业务组 → 商家账户（店铺）→ 商品 → 计划 → 智能助手
```

- GETmore 是智能体名称，不是组织层级。
- 华东/华南是区域经营单元；品牌营销中心是品牌广告团队。
- 同一个商家可以同时有竞价账户和品牌账户，因此同名商品可能出现在两个团队，但 accountId / productId / 计划 / 预算都不同。
- 当前商品 ID 是账户内唯一；若需要跨账户同一 SPU，需要额外 `merchantId / spuId`。

## 3. 创建方式

### 入口一：侧栏

- 按「组织 → 下级组织 → 账户 → 商品」展开；
- 只展示有推广计划的商品；
- 未建立：点击弹出确认；
- 已建立：点击进入工作区；
- 一个商品只允许一个活跃工作区。

### 入口二：数据页商品行

账户抽屉 → 店铺商品 →「创建智能助手 / 进入助手」。

- 无计划商品显示「暂无投放」，不能创建。

## 4. 共享池

工具和技能是全局共享的，不按商品复制。

### 工具

- 账户查询 / 计划查询 / 趋势 / 周期对比
- 预算进度 / 计划清单 / 预算模拟
- 写入类：调整预算、暂停/恢复计划、调整出价

每个工作区只绑定一部分工具；写入工具默认不启用。

### 技能

- 商品投放诊断
- 预算规划
- 直播复盘
- 素材复盘
- 周报生成

工作区保存 `toolIds` / `skillIds`，上下文只加载已启用的技能说明。

## 5. 工作区上下文

固定范围：

```text
商品 → 账户 → 该商品的 1–N 条计划
```

包含：

- 商品价格 / 库存 / 上下架状态
- 账户状态 / 预算 / 余额 / 授权
- 计划 ID / 投放方式 / 目标 / 状态 / 学习期 / 审核原因 / 预算 / 出价
- 近 7 天消耗、支付、订单、ROI、订单成本
- 净成交（仅授权账户）
- 数据健康、缺失字段、延迟
- 最近操作
- 已启用技能说明
- 范围规则：只负责该商品；不判断绝对盈亏

不包含：

- 其他商品 / 账户 / 全站大盘
- 人群、素材、排期等非决策字段
- 商品成本、毛利、物流、退货

## 6. 对话与上下文预算

一个工作区可以有多段对话。

- 每段对话有自己的消息、工具结果、摘要；
- 工作区固定上下文每次重建，不随聊天增长；
- 会话上下文到阈值时提醒新开对话。

预算：约 **32k tokens / 会话**。

```text
60%：提示可以总结或新开
80%：黄色警告
90%：阻止继续发送，要求新开
```

新开对话时：

```text
新会话 = 工作区固定上下文
       + 上一段会话摘要
       + 已确认结论/偏好
       - 原始消息和原始工具结果
```

## 7. 当前实现边界

- 已实现：工作区创建、组织树、账户分组、共享工具/技能绑定、多会话、上下文计量、摘要传递、商品上下文。
- 工具/技能目前只影响上下文和分析建议；写入类工具尚未接入「商品级执行范围校验」。
- 商品对话内也可提交执行提案；提案绑定当前商品/账户/计划，确认后才执行；见 [human-in-the-loop.md](human-in-the-loop.md)。
- 当前工作区为“分析 + 建议”模式：可提交执行提案，优化师确认后才执行；不自动改预算/出价。
- 商品级执行下一步需要：
  - `allowedPlanIds`
  - 服务端二次校验
  - 审批 / diff / 回执 / 撤销
  - 工具白名单和技能白名单

## 8. 面试一句话

> 共享工具池和技能池只定义一次；每个商品一个逻辑工作区，绑定范围、工具、技能、权限和记忆；工作区内可以多段对话，上下文到阈值就带摘要新开，而不是复制一套 Agent。
