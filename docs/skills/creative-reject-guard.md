# 技能 05：素材拒审止损

> 平台越来越自动化，创意成了优化师最核心的杠杆；素材拒审，是创意链路里最直接的止损点。

---

## 1. 为什么做

素材拒审后，计划仍可能继续消耗：

- 全部素材被拒：计划没有可交付素材，继续投就是浪费；
- 部分素材被拒：还有可投素材，直接暂停会误伤；
- 计划已暂停/无消耗：不需要重复提交。

这个技能的答案：

> **全部素材拒审且仍在消耗 → 暂停；部分拒审 → 只观察并提示替换；计划已暂停 → 只观察。**

---

## 2. 怎么设计

```text
查计划消耗
→ 查素材审核状态
→ 统计通过/拒绝数量
→ 全部拒绝且投放中：暂停
→ 部分拒绝：只观察，提示替换
→ 已暂停/无消耗：只观察
```

工具：`query_plans`、`get_account_plans`、`pause_plan`。

---

## 3. 业务关系

| 指标 | 技能怎么影响 |
| --- | --- |
| 拒审素材数 | 判断可交付素材是否归零 |
| 计划消耗 | 全部拒审时优先停高消耗计划 |
| 可交付素材 | 部分拒审时不误停 |
| 退款率 | 低质素材可能带来退款，先止损 |

---

## 4. 评测

| case | 场景 | 期望 |
| --- | --- | --- |
| `cr-001` | 全部素材拒审，计划仍在消耗 | 暂停 |
| `cr-002` | 1/2 拒审，仍有可投素材 | 只观察 |
| `cr-003` | 没有拒审素材 | 只观察 |
| `cr-004` | 全部拒审但计划已暂停 | 只观察 |
| `cr-005` | 素材数据缺失 | 只观察 |

skill 级真实 LLM：**5 / 5**。  
完整工具链：pass@3 3/3（全部拒审 → 暂停）。

---

## 5. 边界

- 只处理“全部素材拒审”的明确止损；
- 部分拒审不暂停，提示替换；
- 不生成“换素材”动作，因为当前工具没有素材替换能力；
- mock 数据，不是线上审核。

---

## 6. 为什么符合业务

平台黑盒化/自动化后，定向和出价被系统接管，**素材成为优化师最核心的变量**。  
素材拒审是创意链路里最确定、最可执行的止损点，不需要预测算法，只需要看审核状态和消耗。
