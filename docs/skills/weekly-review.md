# 技能 06：周报复盘

> 不是每个技能都要“动投放”。周报是优化师高频、重复、但直接决定下周动作的工作。

---

## 1. 为什么做

优化师每周都要：

- 拉本周数据；
- 对比上周；
- 找关键变化；
- 写下周动作；
- 在群里/周会上讲清楚。

这件事重复、耗时，而且容易漏掉数据缺口。

这个技能的答案：

> **固定结构输出周报：本周总览 → 本周 vs 上周 → 3 个关键变化 → 2 个下周动作 → 数据缺口。只读，不提交 Decision。**

---

## 2. 怎么设计

```text
拉本周账户/计划汇总
→ 对比本周 vs 上周
→ 找 3 个关键变化
→ 给 2 个下周动作
→ 显式写数据缺口
```

工具：`query_accounts`、`query_plans`、`compare_periods`、`get_org_summary`。

---

## 3. 业务关系

| 指标 | 技能怎么影响 |
| --- | --- |
| 消耗 / GMV / ROI | 周报总览 |
| 订单成本 | 判断效率变化 |
| 数据完整度 | 缺数据要写明，不能推断为 0 |
| 决策时间 | 从手工拉数变成可复核周报 |

---

## 4. 评测

| case | 场景 | 期望 |
| --- | --- | --- |
| `wk-001` | 正常一周 | 输出周报 |
| `wk-002` | 数据延迟 + 部分授权 | 周报写明缺口 |
| `wk-003` | 本周无消耗 | 不硬写增长 |
| `wk-004` | 退款数据缺失 | 不推断 |
| `wk-005` | 品牌账户，无支付 ROI | 不套竞价 ROI |

skill 级真实 LLM：**5 / 5**。  
只读评测：pass@3 3/3，不生成 Decision。

---

## 5. 边界

- 只读，不提交动作；
- 不写“已执行”；
- 缺数据显式说明；
- 不把品牌广告套支付 ROI。

---

## 6. 为什么符合业务

平台自动化后，优化师的价值从“手动调参”转向“数据解读、复盘、下周策略”。  
周报是最能体现这个转变的高频工作，而且不需要新工具，现有数据就能做。
