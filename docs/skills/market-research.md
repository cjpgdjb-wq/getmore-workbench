# 优化师到底需要什么技能：外部调研 + 技能选择

> 先看真实工作，再决定做什么 skill。  
> 结论：平台越自动化，优化师越不像“调参员”，越像“策略 + 创意 + 数据复盘”的人。

---

## 1. 外部调研

### 1.1 平台黑盒化后，工作重心转移

[鸟哥笔记：投放平台黑盒化后，优化师们的工作重心如何转移？](https://www.niaogebiji.com/article-705246-1.html)（2025-10-13）提到：

- 平台强制全平台推广，优化师不能再靠独立版位/手动定向；
- 工作重心从“平台指标”转向 LTV、GMV、品牌健康度；
- 素材从“少量爆款靠感觉”转向“大规模假设-测试-迭代”；
- 优化师要会 AI 工具、数据解读、A/B 测试；
- 未来是“商业策略 + 人群洞察 + 业务赋能”的三角人才。

### 1.2 UBMax / 自动化投放时代

[鸟哥笔记：UBMax 时代下，优化师还能做什么？](https://www.niaogebiji.com/article-701521-1.html)（2025-04-14）提到：

- UBMax 自动学习版位、预算、创意、出价；
- 优化师转向：投放目标/策略、人群细分、预算分配、创意策略、数据分析、平台新功能；
- 手动调参价值下降，**预算分配、创意、数据洞察**价值上升。

### 1.3 素材复盘是核心工作

[蝉妈妈：千川素材跑量差怎么复盘？](https://www.chanmama.com/yunyingquan/article/2586.html)（2026-10-07）给了一个很具体的复盘框架：

- 5 秒完播率、点击率、转化率的三段式漏斗；
- 受众画像是否偏离；
- 素材生命周期：连续 3 天跑量分下降 + ROI 下滑，才考虑迭代；
- 竞品素材变化；
- 单变量测试，新素材至少跑 2 天再下结论。

注意：这篇给了方法，但我们的 mock 数据没有素材级消耗/CTR/CVR，所以不能假装做“素材衰退诊断”。

### 1.4 净成交/退款成为经营口径

[巨量学：直播全域-净成交出价产品手册](https://school.jinritemai.com/doudian/wap/course-series/cJZHjLnhaLyw/cJZHjLnhaLywlJZJUawr8qMk) 说明平台已在推“净成交出价”。

对优化师的含义：

- 支付 ROI 好看，不代表净成交/利润好；
- 退款率、净成交金额要进入判断；
- 不能只看支付口径。

## 2. 调研结论：优化师需要 5 类能力

| 能力 | 具体工作 | 是否适合做 skill |
| --- | --- | --- |
| **策略/预算** | 预算分配、止损、放量 | ✅ 已有：预算重排、学习期诊断 |
| **创意** | 素材审核、衰退、替换、A/B | ⚠️ 部分：拒审可做；衰退缺素材级数据 |
| **数据/复盘** | 周报、异常归因、对比 | ✅ 可做：周报复盘 |
| **经营质量** | 退款、净成交、利润 | ✅ 可做：退款异常诊断 |
| **平台/算法** | 出价、定向、UBMax 设置 | ⚠️ 自动化接管，优先级下降 |

---

## 3. 为什么选这 3 个新技能

### 3.1 退款异常诊断

- 对应“经营质量”，直接关系利润；
- 数据已有 `refundRate`、`netRevenue`、`netOrders`；
- 有明确动作：降 10% / 只观察；
- 能说清失败边界：未授权、计划暂停、低消耗只观察。

### 3.2 素材拒审止损

- 对应“创意”里最确定、最可执行的一段；
- 数据已有素材审核状态、拒审原因、计划消耗；
- 全部拒审 + 仍在消耗 → 暂停；部分拒审 → 只观察；
- 不假装做“素材衰退”，因为缺素材级效果数据。

### 3.3 周报复盘

- 对应“数据/复盘”，高频、重复、耗时；
- 数据已有账户/计划/周期对比；
- 只读，不生成 Decision；
- 能显式暴露数据缺口，符合“数据诚实”。

---

## 4. 为什么暂时不做

| 技能 | 原因 |
| --- | --- |
| 素材衰退诊断 | 有素材审核/标题，但没有素材级消耗、CTR、CVR、完播率，做了就是编 |
| 人群重叠/偏移 | 有人群定向，但没有人群体级效果，无法归因 |
| 出价诊断 | UBMax/自动出价接管，手动出价杠杆下降；优先级低于预算/创意/退款 |
| 品牌 ROI 诊断 | 品牌只有曝光/点击/CPM/CTR，没有支付 ROI，不能套竞价逻辑 |
| 自动加预算 | 历史回放显示加预算模板不可靠，先不做自动加 |

## 5. 六个技能地图

| Skill | 类型 | 状态 |
| --- | --- | --- |
| 学习期诊断 | 策略/止损 | 10/10；pass@3 3/3 |
| 预算重排 | 预算 | 10/10；pass@3 3/3 |
| 库存止损 | 供给/止损 | 10/10；pass@3 3/3 |
| 退款异常诊断 | 经营质量 | 5/5；pass@3 3/3 |
| 素材拒审止损 | 创意/止损 | 5/5；pass@3 3/3 |
| 周报复盘 | 数据/复盘 | 5/5；只读 pass@3 3/3 |

---

## 6. 设计原则

1. 先有数据，再做 skill；
2. 先有业务动作，再做 skill；
3. 先有失败边界，再做 skill；
4. 先有评测，再谈上线；
5. 不是每个 skill 都要 Decision：周报是只读工作流；
6. 不为了“技能数量”做假数据。

---

## 7. 面试一句话

> 我调研了平台黑盒化、UBMax 和净成交出价后的优化师工作，发现真正高频的是预算、创意、退款/净成交、复盘。  
> 所以我做了学习期、预算、库存、退款、素材拒审、周报六个 skill；  
> 素材衰退和人群重叠没有数据支撑，我明确不做，而不是编一个。
