# GETmore 模拟数据说明

本目录用于给 Copilot 提供可读取的示例数据说明。工作台的演示数据在浏览器本地生成，**不会上传到服务器**。

- 账户数量：竞价 22 个、品牌 12 个
- 组织层级：GETmore 集团 → 华东 / 华南事业群、品牌直营中心 → 事业组
- 指标口径：
  - 整体消耗（元）
  - 整体成交订单数
  - 用户实际支付金额（元）
  - 整体支付ROI = 用户实际支付金额 / 整体消耗
  - 整体成交订单成本 = 整体消耗 / 整体成交订单数
  - 净成交金额 / 净成交订单 / 净成交ROI：依赖商品交易授权，未授权为“未同步”，不能当 0
  - 1 小时退款率：千川报表口径，不等于最终退货率
  - 品牌：展示次数、点击次数、点击率 = 点击次数 / 展示次数、平均千次展现费用 = 消耗 / 展示次数 × 1000
- 数据健康：
  - 报表约 5 分钟刷新；部分账户存在 2–22 分钟延迟
  - 净成交/退款、素材、有效余额、共享钱包可能因授权缺失
  - 缺失字段不能推断为 0
- 不提供：商品成本、毛利、物流、税费、最终退货率、竞品、自然流量增量
  - 因此不能判断绝对盈亏，不要输出“保本 / 盈利 / 亏损”结论

> 全部为本地模拟数据，仅用于产品演示，不代表任何真实账户表现。
