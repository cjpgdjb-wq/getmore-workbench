# 库存止损

商品库存快断时，判断计划该暂停、降预算还是只观察。

## 什么时候用

- 库存快断
- 库存只剩 3 天
- 这个计划还要不要投

## 业务问题

高消耗计划还在放量，但商品库存只剩 1–3 天；继续投会带来退款、差评和履约压力，只停计划又可能误伤正常计划。

## 方法

先查计划消耗和商品库存，再算可售天数；库存 ≤3 天且计划仍在投放时，优先暂停或降 20%；库存充足、数据缺失或商品已下架时只观察。

## 步骤

1. 先看数据健康：库存/商品数据是否可用
2. 查计划消耗、商品库存、可售天数
3. 库存 ≤3 天且计划仍在投放：优先暂停
4. 库存 4–7 天：降预算 20%，不直接暂停
5. 库存充足或数据缺失：只观察

## 护栏

- 不向库存不足的商品加预算
- 暂停/降预算可回滚

## 失败处理

库存数据缺失、商品已下架、计划已暂停时，只观察，不提交动作。
