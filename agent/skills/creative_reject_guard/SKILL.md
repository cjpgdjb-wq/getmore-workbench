# 素材拒审止损

素材被拒审、计划还在花钱时，判断该暂停还是只观察。

## 什么时候用

- 素材拒审
- 没有可投素材
- 计划还在消耗

## 业务问题

素材拒审后计划仍可能继续消耗；如果全部素材都被拒，计划实际上没有可交付素材，继续投就是浪费。

## 方法

先查计划消耗和素材审核状态；全部素材拒审且仍在消耗 → 暂停；部分拒审 → 只观察并提示替换；计划已暂停/无消耗 → 只观察。

## 步骤

1. 查计划消耗和素材审核状态
2. 统计通过/拒绝素材数
3. 全部素材拒审且计划仍在消耗：暂停
4. 只有部分拒审：只观察，提示替换被拒素材
5. 计划已暂停/无消耗：只观察

## 护栏

- 不重复暂停
- 暂停可回滚

## 失败处理

素材数据缺失、计划已暂停、无消耗时，只观察；全部拒审时不得建议恢复投放。
