# 学习期诊断

判断学习期计划该继续、降预算还是只观察，避免误停和误加。

## 什么时候用

- 计划处于学习期
- ROI 低于目标
- 用户问要不要降预算/暂停

## 业务问题

学习期计划 ROI 低于目标时，优化师容易走两个极端：直接暂停打断学习，或继续加预算越投越亏。

## 方法

把判断固定成一条顺序：数据健康 → 学习期天数 → ROI/订单成本 vs 目标 → 库存/余额 → 只观察或降 10%。样本不足、数据缺失、库存/余额不足时一律只观察。

## 步骤

1. 先看数据健康：延迟、授权、缺失字段
2. 确认是否在学习期，以及学习第几天
3. 对比 7 天 ROI / 订单成本与计划目标
4. 检查消耗占比、库存可售天数、账户余额
5. 样本不足（转化 <20/天）只观察；否则给出降预算或观察建议

## 护栏

- GMV ≥ -5%
- 库存 ≥7 天
- 余额 ≥3 天

## 失败处理

数据延迟/缺失、样本不足、库存不足时，只观察，不硬下结论。
